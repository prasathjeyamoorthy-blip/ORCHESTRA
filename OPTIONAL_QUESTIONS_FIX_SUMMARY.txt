THE PROBLEM:
------------
• User clicks Tamil (தமி) button ✓
• Starts PAN application ✓  
• Q1: Clicks "இந்திய குடிமகன்" (Indian Citizen) ✗
• System doesn't recognize response
• Asks SAME question again
• User clicks again → same question → STUCK!
• Only ONE question showing, never advancing to Q2, Q3, etc.

ROOT CAUSE:
-----------
Translation was only in DISPLAY layer, not MATCHING layer!

When user clicks Tamil option:
  Frontend sends: "இந்திய குடிமகன்" (Tamil text)
       ↓
  Backend tries to match: r"\b(indian\s+citizen)\b" (English regex)
       ↓
  NO MATCH! ❌
       ↓
  Asks same question again (infinite loop)

THE FIX:
--------
Added multilingual response matching to ALL optional questions!

OLD CODE (receptionist.py line 1270):
  _indian = re.compile(r"\b(indian\s+citizen|indian)\b", re.IGNORECASE)
  if _indian.search(user_input):  # ❌ Only English!
      advance_to_next_question()

NEW CODE (receptionist.py lines 1265-1292):
  # English
  _indian = re.compile(r"\b(indian\s+citizen|indian)\b", re.IGNORECASE)
  
  # ✅ Tamil
  _indian_ta = re.compile(r"(இந்திய\s*குடிமகன்|குடிமகன்)", re.IGNORECASE)
  
  # ✅ Hindi  
  _indian_hi = re.compile(r"(भारतीय\s*नागरिक|नागरिक)", re.IGNORECASE)
  
  # Check ALL patterns
  if _indian.search(inp) or _indian_ta.search(inp) or _indian_hi.search(inp):
      advance_to_next_question()  # ✅ NOW works in all languages!
