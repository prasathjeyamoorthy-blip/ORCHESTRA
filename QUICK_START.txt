═══════════════════════════════════════════════════════════════════════════════
                                TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Service won't start:
    → Check port not in use: netstat -ano | findstr :8000

Module not found:
    → Activate venv: cd service && .venv\Scripts\activate

Document agent offline:
    → Start pan_verification first (Terminal 1)

Review app won't open:
    → Check tkinter installed: python -m tkinter

Browser doesn't open:
    → Install Chromium: cd automation_agent && playwright install chromium

reCAPTCHA fails:
    → Click checkbox manually when browser pauses
