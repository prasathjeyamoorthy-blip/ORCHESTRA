Why birth certificate matters:

    User uploads birth certificate PDF

        ↓
    finalize-application merges data:
        • Aadhaar says DOB: "15/08/1995"

        •
        • DECISION: Use birth cert DOB (more authoritative for age proof)
        •
        • automation_data["dob"] = "18/01/2008" ✓
        ↓
    automation_agent submits form with birth cert DOB
        ↓
    ✅ NSDL accepts application with correct DOB from official birth certificate

                              KEY QUESTIONS ANSWERED
═══════════════════════════════════════════════════════════════════════════════

Q: Which agent gives the final JSON to automation_agent?
A: pan-rag's finalize-application endpoint (the integration orchestrator)

Q: Is FlowManager an orchestrator?
A: No, it's just a conversation state tracker (knows which step user is on)

Q: Does Orchestra do the orchestration?
A: No, Orchestra is for multi-doc validation (not yet integrated)

Q: Does automation agent receive birth certificate?
A: ✅ YES! Birth cert is extracted, cached, merged, file copied, and path included

Q: Who knows about all the agents?
A: Only finalize-application - it's the ONLY component that talks to everyone

Q: What happens when documents conflict?
A: finalize-application has resolution rules (e.g., birth cert DOB > Aadhaar DOB)
