# PAN Assistant — Quick Start

Open a **separate terminal** for each service.

---

## 1. Node Backend — port 4000

```bash
cd auth-app/backend
npm install
node server.js
```

---

## 2. PAN RAG Agent — port 8000

```bash
cd pan-rag
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload
```

---

## 3. Voice Agent — port 8002

```bash
cd pan-rag
.venv\Scripts\activate
uvicorn api.voice_main:app --host 0.0.0.0 --port 8002 --reload
```

> Voice agent shares the same `.venv` as pan-rag. No separate install needed.

---

## 4. Document Upload Agent — port 5001

```bash
cd documentuploadagent
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py ---> only for initial testing
```

---
    
## 5. Frontend — port 5173

```bash
cd frontend
npm install
npm run dev
```

---
