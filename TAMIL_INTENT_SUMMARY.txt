PROBLEM:
--------
Agent wasn't understanding Tamil user inputs:
• "epdi da irukka" → responded in English

ROOT CAUSE:
-----------

• Limited keywords (missing colloquial words)

• No fallback for mixed/longer texts

SOLUTION:
---------

1️⃣ NATIVE SCRIPT DETECTION (highest priority)

2️⃣ LANGDETECT LIBRARY (for longer texts)
   • Added langdetect==1.0.9 to requirements
   • Better accuracy on mixed script
   
3️⃣ KEYWORD MATCHING (for romanized text)
   • Added 40+ new Tamil colloquial words:
     - Informal: da, di, pa, ma, ba
     - Common: epdi, irukka, sollu, pannu
     - Questions: yaar, enga, eppo, evlo
