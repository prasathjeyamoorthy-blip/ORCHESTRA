# .gitignore Documentation

## Overview
This `.gitignore` file prevents sensitive data, build artifacts, dependencies, and temporary files from being committed to the Git repository.

## Critical Categories Being Ignored

### 🔐 Secrets & Credentials (NEVER commit these!)
```
.env                    # Environment variables
.env.*                  # Environment-specific files
credentials.json        # Google Cloud credentials
service-account-key.json
*.key                   # Private keys
*.pem                   # Private certificates
!.env.example           # Exception: Keep template
```

**Why**: Exposing API keys, database credentials, or private keys compromises security.

### 📦 Dependencies
```
node_modules/           # Node package dependencies
.venv/                  # Python virtual environment
venv/                   # Alternative venv name
env/                    # Alternative env name
```

**Why**: Dependencies are specified in `package.json` or `requirements.txt` and can be reinstalled. Committing them bloats the repo (500MB+).

### 🏗️ Build & Artifacts
```
dist/                   # Built frontend files
build/                  # Build output
.next/                  # Next.js build output
.nuxt/                  # Nuxt build output
out/                    # Various build outputs
wheels/                 # Python wheel distributions
*.egg-info/             # Python egg info
```

**Why**: These are generated from source and can be recreated. No need to track them.

### 🤖 ML Model Cache (Large Files)
```
pan-rag/hf_cache/       # HuggingFace model cache (multi-GB)
pan-rag/models/         # Downloaded models
voice-agent/hf_cache/   # Voice model cache
transformers_cache/     # Transformers library cache
```

**Why**: Model files are 100MB-10GB each. Download on first run instead.

### 📊 Database & Cache
```
*.db                    # SQLite databases
*.sqlite                # SQLite databases
*.sqlite3               # SQLite databases
pan-rag/chroma_db/      # Vector database
.cache/                 # Application cache
```

**Why**: These are generated/downloaded at runtime. Rebuild on each environment.

### 📁 Uploaded Data & Storage
```
pan-rag/storage/        # User uploads
uploads/                # All uploads
*.uploadcache           # Upload cache files
temp/                   # Temporary files
tmp/                    # Temporary files
```

**Why**: User data is environment-specific and can be large. Store separately.

### 🎤 Voice Agent Data
```
voice-agent/audio_cache/
*.wav                   # Audio files
*.mp3                   # Audio files
*.flac                  # Audio files
*.ogg                   # Audio files
```

**Why**: Generated or user-uploaded audio files.

### 🧪 Test & Debug Files

.coverage               # Code coverage reports
htmlcov/                # Coverage HTML reports

## How to Use This .gitignore

### Adding Files to Ignore
Edit `.gitignore` and add a new line with the pattern:

```bash
# Single file
config.local.json

# File extension
*.temp

# Directory
my_cache/

# Wildcard pattern
temp_*
```

### Forcing Commit of Ignored File
If you need to commit an ignored file:

```bash
git add -f ignored_file.txt
git commit -m "Force add ignored file"
```

### Checking What's Ignored
```bash
git check-ignore -v *                # Show ignored files
git status --ignored                 # Show all ignored files
```

## Important Reminders

### ⚠️ DO NOT COMMIT:
- ❌ `.env` files with real credentials
- ❌ `node_modules/` or `.venv/`
- ❌ AWS keys, API tokens, passwords
- ❌ Uploaded user files
- ❌ Database files with real data
- ❌ Large ML model files

### ✅ DO COMMIT:
- ✅ Source code (`.py`, `.jsx`, `.js`)
- ✅ Configuration templates (`.env.example`)
- ✅ Package specifications (`package.json`, `requirements.txt`)
- ✅ Documentation files
- ✅ Configuration files without secrets
- ✅ `.gitignore` itself

## Troubleshooting

### Already Committed Secret?
Remove from history:
```bash
git rm --cached .env
git commit --amend --no-edit
git push --force-with-lease
```

### File Should Be Ignored But Isn't?
1. Check if it's listed in `.gitignore`
2. If listed but still showing: `git rm --cached filename`
3. Add to `.gitignore`
4. `git commit -m "Ignore file"`

### File Should NOT Be Ignored But Is?
Add exception with `!` prefix:
```
# In .gitignore
*.log           # Ignore logs
!important.log  # Except this one
```

## Security Best Practices

### Before Committing
```bash
# Check for sensitive data
git diff --staged | grep -i "key\|password\|secret\|token"

# Verify no .env files
git status | grep -E "\.(env|key|pem|json)"
```

### If Accidental Commit
```bash
# Remove from latest commit (not pushed)
git reset --soft HEAD~1
git reset .env
git commit --amend -m "Remove .env"

# If already pushed - use git-filter-branch or BFG Repo Cleaner
```
