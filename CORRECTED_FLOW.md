# CORRECTED FLOW - Simple & Direct

## The Right Way (No Session IDs, No Tkinter)

```
User completes application in frontend
    ↓
Frontend calls: POST /api/finalize-application
    ↓
Backend generates: automation_agent/INPUT.json
    ↓
User manually reviews INPUT.json
    ↓
User runs: cd automation_agent && python main.py
    ↓
Browser opens, form fills, application submits
    ↓
Payment URL saved
```

## Step-by-Step Testing

### 1. Start Services

```bash
# Terminal 1: pan_verification
cd d:\PANCARD\pan_verification
.venv\Scripts\activate
python app.py

# Terminal 2: pan-rag
cd d:\PANCARD\pan-rag
.venv\Scripts\activate
uvicorn api.main:app --reload --port 8000

# Terminal 3: Node Backend
cd d:\PANCARD\auth-app\backend
npm run dev

# Terminal 4: Frontend
cd d:\PANCARD\frontend
npm run dev
```

### 2. Complete Application in Frontend

1. Open http://localhost:5173
2. Login/Create account
3. Chat: "I want to apply for PAN"
4. Upload 3-4 documents (Aadhaar, Photo, Sign, DL)
5. Answer questions (name, email, income)
6. Confirm details
7. **Click "Submit Application" button** (when you add it to frontend)

### 3. Frontend Calls Finalize

The frontend button should call:

```javascript
const response = await fetch('/api/finalize-application', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({
    session_id: currentSessionId,
    trigger_automation: false  // Just prepare, don't run yet
  })
});

const result = await response.json();
console.log(result.message);
```

**Response:**
```json
{
  "status": "success",
  "message": "✅ Application data prepared successfully!\n\n📄 Next Steps:\n1. Review: automation_agent/INPUT.json\n2. Run: cd automation_agent && python main.py",
  "input_file": "d:/PANCARD/automation_agent/INPUT.json"
}
```

### 4. Review INPUT.json

```bash
# View the generated file
type automation_agent\INPUT.json
```

**Or open in VS Code:**
```bash
code automation_agent\INPUT.json
```

**Verify:**
- ✅ Name split correctly (Anand R Ajaanand → first=Ajaanand, middle=R, last=Anand)
- ✅ All 30 fields present
- ✅ File paths correct (docs/jphoto.jpeg, docs/jaadhar.pdf, etc.)
- ✅ No critical fields empty

### 5. Run Automation

```bash
cd automation_agent
.venv\Scripts\activate
python main.py
```

**What happens:**
1. Reads `INPUT.json`
2. Chrome opens (visible, headless=False)
3. Navigates to NSDL portal
4. Fills form automatically
5. Uploads documents
6. Solves reCAPTCHA
7. Submits application
8. Captures payment URL
9. Saves `payment_link.json`

### 6. Check Results

```bash
# View payment link
type automation_agent\payment_link.json

# View screenshot
start automation_agent\payment_page.png
```

## Troubleshooting

### "INPUT.json not found"
**Cause:** Finalize endpoint not called or failed
**Fix:** Check pan-rag logs, ensure frontend called `/api/finalize-application`

### "Name not split correctly"
**Check:** Open INPUT.json and verify first/middle/last names
**Fix:** If wrong, edit INPUT.json manually before running automation

### "Files not in docs/"
**Cause:** Documents not uploaded or upload failed
**Fix:** Check pan-rag/storage/uploads/{session_id}/ has files

### "Browser doesn't open"
**Fix:** `cd automation_agent && playwright install chromium`

## What to Check in INPUT.json Before Running Automation

### Critical Fields (Must Be Filled):
- [ ] first_name OR last_name (at least one)
- [ ] email
- [ ] aadhaar_first_8 (8 digits)
- [ ] aadhaar_last_4 (4 digits)
- [ ] dob (DD/MM/YYYY format)

### File Paths (Must Exist):
- [ ] photo_file: "docs/jphoto.jpeg"
- [ ] signature_file: "docs/jsign.jpeg"  
- [ ] aadhaar_pdf: "docs/jaadhar.pdf"

### Name Splitting (South Indian Logic):
If you entered "Anand R Ajaanand", verify:
- [ ] first_name: "Ajaanand" (father's name)
- [ ] middle_name: "R" (initial)
- [ ] last_name: "Anand" (given name)

If wrong, **edit INPUT.json manually** before running `python main.py`.

## Complete Flow Diagram

```
┌─────────────────────────────────────────────────────────────┐
│                    USER SIDE                                │
└─────────────────────────────────────────────────────────────┘

1. User opens frontend (http://localhost:5173)
2. User uploads 3-4 documents
3. User answers questions in chat
4. User confirms details
5. User clicks "Submit Application" button

        ↓ POST /api/finalize-application

┌─────────────────────────────────────────────────────────────┐
│                   BACKEND SIDE                              │
└─────────────────────────────────────────────────────────────┘

6. Node backend receives request
7. Forwards to pan-rag
8. pan-rag finalize-application endpoint:
   a. Loads FlowManager state
   b. Loads document extractions from Redis
   c. Merges into 30-field schema
   d. Copies files to automation_agent/docs/
   e. Writes automation_agent/INPUT.json
   f. Returns success message

        ↓ Response to frontend

9. Frontend shows: "✅ Data prepared! Review INPUT.json"

        ↓ User action required

┌─────────────────────────────────────────────────────────────┐
│                  DEVELOPER SIDE                             │
└─────────────────────────────────────────────────────────────┘

10. Developer opens: automation_agent/INPUT.json
11. Developer reviews all 30 fields
12. Developer verifies name splitting
13. Developer checks file paths
14. Developer runs: python main.py

        ↓ Browser automation

15. Chrome opens (visible)
16. Form fills automatically
17. Documents upload
18. Application submits
19. Payment URL captured

        ↓ Done!

20. payment_link.json created with URL
```
